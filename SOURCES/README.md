# Sources and Provenance

This directory stores bibliographies, source evaluations, and research provenance for The Architecture of Belief.

## Minimum source record

For every source, record:

- author, editor, or responsible institution;
- full title;
- publication date and publisher, journal, or issuing body;
- URL, DOI, ISBN, archival identifier, or other stable locator;
- source type (primary text, official doctrine, historical record, ethnography, scholarly analysis, scientific study, or general reference);
- date accessed, when relevant;
- the exact claim(s) for which the source is being used;
- limitations, perspective, and known disputes.

## Source discipline

- Prefer primary sources for what a tradition or institution officially teaches.
- Use reputable scholarship to explain historical context and interpretive disagreement.
- Use community-specific sources when describing living or Indigenous traditions.
- Use scientific literature for empirical claims, not as a substitute for theological sources.
- Do not treat search snippets, unsourced social posts, or AI-generated summaries as authoritative evidence.
- Verify quotations against the cited source.
- Never invent bibliographic details or imply that an unread source was checked.

A bibliography is not proof by itself. Each citation must support the specific statement attached to it.
